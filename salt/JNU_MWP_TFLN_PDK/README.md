# JNU_MWP_TFLN_PDK V1.1

固定器件仅保留 600 nm 膜厚 / 300 nm 刻蚀 / 63° 实际侧壁角：24 个器件，108 个光学端口。三个 Library 包括工艺分组库、独立黑盒库和九个 PCell。

## LN 芯片参数

芯片层栈参数：

| 参数 | 规格 |
|---|---|
| LN 薄膜 / Etch depth / Slab | 600 nm / 300 nm / 300 nm |
| BOX（埋氧层） | 2 µm；材料未单独注明 |
| Top cladding（参考加工流程） | SiO₂，沉积厚度 1 µm，兼作电极与波导隔离层 |
| 晶向 / 传播方向 / 侧壁角 | X-cut / Y 或 Z / 63° |
| 波导宽度基准 | 上表面宽度 |
| NiCr / Au 电极厚度 | 200 nm / 1 µm |
| 支撑衬底与芯片尺寸 | 加工需求未明确，待确认 |

器件清单包含 AIR（7 个）、SiO₂（10 个）、SiON（6 个）及包层待确认（1 个）版本。1 µm SiO₂ 是参考加工流程的沉积要求，各器件仿真包层厚度需分别核对；SiON 的厚度及折射率未在该加工需求中给出。这些要求不代表已完成制造或验收。
